# Preprint

`paper.tex` is the arXiv-ready source. Build with any LaTeX engine:

```bash
tectonic paper.tex        # self-contained, no TeX installation needed
```

Submission metadata (title, abstract, categories, endorsement notes) is in
[`../docs/ARXIV_SUBMISSION.md`](../docs/ARXIV_SUBMISSION.md).

Submit only after the Zenodo DOI exists, so the artifact is cited as an
archived deposit rather than a bare repository URL.
